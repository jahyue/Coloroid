# Coloroid

A simple online photobooth for two people, no matter how far apart they are.

## About

Coloroid lets two people connect through their cameras and take photos together in a virtual photobooth. It combines both camera feeds into one view and creates a photo strip of their shared moments.

## Features

- Create and join rooms using an invite link
- Connect two cameras in real time
- Side-by-side camera display
- Synchronized photo capture
- Three-photo photobooth strip
- Retake and download your photo strip

## Built With

- HTML
- CSS
- JavaScript
- PeerJS
- WebRTC
- HTML Canvas

## How to Use

1. Open Coloroid.
2. Select **Create Room** to host a session.
3. Share the invite link with another person.
4. The other person opens the link and joins.
5. Allow camera and microphone access.
6. Both participants select Ready.
7. Take your photos and enjoy your photo strip!
